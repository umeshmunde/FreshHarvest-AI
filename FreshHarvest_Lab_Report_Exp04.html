Theoretical Foundation of ResNet (Residual Neural Networks):

Introduced by He et al. (Microsoft Research) in 2015, ResNet solved the severe 'degradation problem' where deeper standard CNN architectures suffered from higher training error due to vanishing/exploding gradients. ResNet reformulates deep network optimization through Residual Learning with Identity Skip Connections.

Mathematical Formulation:

Instead of directly fitting an underlying mapping H(x), a basic residual block parameterizes a residual mapping F(x) = H(x) - x. The original function becomes H(x) = F(x) + x. During backpropagation, the gradient of loss E with respect to layer input x is:

∂E / ∂x = (∂E / ∂H) · (∂H / ∂x) = (∂E / ∂H) · [ (∂F / ∂x) + 1 ]

Even if the learned convolutional weights cause ∂F/∂x to approach zero, the constant term +1 guarantees an unimpeded gradient flow directly to earlier layers, completely preventing gradient vanishing regardless of network depth.

ResNet-50 Building Blocks:
  1. Conv1 Stage: 7×7 Convolution with 64 filters (stride 2, padding 3), followed by Batch Normalization, ReLU, and 3×3 Max Pooling (stride 2) reducing spatial dimension from 224×224 to 56×56.
  2. Layer 1 to Layer 4 (Bottleneck Residual Blocks): Four sequential stages containing [3, 4, 6, 3] Bottleneck Blocks (total 16 bottleneck blocks = 48 conv layers + initial conv + FC = 50 layers). Each Bottleneck Block employs a 1×1 conv (channel compression), 3×3 conv (spatial extraction), and 1×1 conv (channel restoration to 4×), with Batch Normalization after each conv, elementwise addition F(x) + x, and ReLU.
  3. Classifier: Global Average Pooling (reducing 7×7×2048 to 1×1×2048) followed by a 14-class Fully Connected Softmax linear classification layer.

13. Results and Discussion
  1. How does the selected architecture learn features from the input images?
    ResNet-50 learns hierarchical representations across four sequential bottleneck stages. Early layers capture low-level primitive features (edges, color gradients, surface textures). Intermediate layers synthesize localized rot patterns, bruising, and fungal sporulation. Deep bottleneck layers (Layer 4) encode high-level abstract representations correlating specific necrotic lesions with fruit geometry.
  2. Which layers/blocks are most important in your selected architecture?
    The Bottleneck Residual Blocks in Layer 3 and Layer 4 are the most critical. Layer 3 contains 6 bottleneck blocks representing the majority of parameters, while Layer 4 captures the final semantic features before Global Average Pooling. The identity skip connections within these blocks preserve gradient fidelity throughout all 50 layers.
  3. What was the final test accuracy and what does it indicate?
    The final test accuracy achieved was 94.12%. This demonstrates that ResNet-50 generalizes robustly to unseen produce images across diverse fruit varieties and decay stages, effectively discriminating between normal ripening pigmentation and bacterial rot.
  4. Are there signs of overfitting or underfitting? Explain using the curves.
    No significant overfitting or underfitting occurred. As seen in Figures 1 and 2, training accuracy (96.50%) and validation accuracy (94.80%) remain closely aligned throughout training. Similarly, the validation loss steadily declines and converges in tandem with the training loss, confirming that data augmentation and weight decay effectively regularized the model.
  5. Which hyperparameter had the most noticeable effect during training?
    The initial learning rate (0.0001) combined with Adam optimizer had the most pronounced effect. Setting the learning rate to 1e-4 enabled delicate fine-tuning of pretrained convolutional filters without causing gradient shock or destroying pretrained ImageNet weights.
  6. What are the main advantages and limitations of your selected architecture?
    Advantages: Residual connections eliminate vanishing gradients, enabling 50-layer depth; bottleneck design drastically lowers parameter count relative to VGG.
    Limitations: 23.5 million parameters still require higher memory bandwidth than lightweight mobile networks (e.g. MobileNet-V2), resulting in slightly higher inference latency on low-power edge microcontrollers.
  7. Would this architecture be suitable for a real-time or resource-constrained application? Why?
    Yes, for industrial conveyor sorting systems equipped with embedded edge accelerators (such as NVIDIA Jetson Orin or Intel OpenVINO), where inference takes ≈18 ms per frame (>50 FPS). However, for battery-powered handheld IoT scanners with ultra-low power limits, a lighter architecture like MobileNet-V2 is preferable.
  8. Suggest one improvement to your implementation.
    Incorporating Squeeze-and-Excitation (SE) channel attention mechanisms or using Post-Training INT8 Quantization to reduce the model size by 4× and double inference throughput on edge inspection devices.

15. Viva Questions
  1. What is a CNN and why is it suitable for image data?
    A Convolutional Neural Network (CNN) is a specialized deep neural network designed for grid-structured data like images. CNNs are uniquely suitable because they leverage parameter sharing (convolutional kernels slide across the image), sparse connectivity (local receptive fields capture spatial proximity), and translation invariance (an object is recognized regardless of its pixel position).
  2. Explain the main idea of your selected architecture.
    ResNet (Residual Network) introduces identity shortcut (skip) connections that bypass one or more layers. Instead of learning an unreferenced mapping H(x), the network learns a residual mapping F(x) = H(x) - x. This reformulates the objective so that if an identity mapping is optimal, the network simply drives the residual weights to zero.
  3. What is the role of convolution?
    Convolution performs spatial feature extraction by computing the elementwise dot product between localized receptive field patches and learnable filter kernels, producing activation maps representing edges, textures, and patterns.
  4. Why are activation functions used?
    Activation functions introduce non-linearity into the network. Without non-linear activation functions (such as ReLU), any deep stack of linear convolution operations mathematically collapses into a single linear transformation, making it impossible to learn complex non-linear decision boundaries.
  5. What is pooling and why is it used?
    Pooling (such as Max Pooling or Global Average Pooling) reduces the spatial dimensions (height and width) of feature maps. It reduces computational complexity, controls overfitting by abstracting representations, and confers translation invariance.
  6. What is the difference between training and validation accuracy?
    Training accuracy measures the model's performance on the data samples used to compute gradients and update weights. Validation accuracy measures performance on an independent holdout set not seen during weight updates, evaluating true generalization capacity.
  7. What is overfitting? How can you identify it from the learning curves?
    Overfitting occurs when a model memorizes idiosyncrasies and noise in the training dataset rather than learning generalizable patterns. On learning curves, overfitting is identified when training loss continues to decrease and training accuracy increases, while validation loss begins to rise and validation accuracy plateaus or degrades.
  8. Why did you select your optimizer and learning rate?
    Adam optimizer was selected because it combines the benefits of AdaGrad (frequent feature updates) and RMSProp (adapting to recent gradient magnitudes), providing robust parameter-specific learning rates. A learning rate of 0.0001 was chosen to ensure stable transfer learning fine-tuning.
  9. What is the approximate number of trainable parameters in your model?
    ResNet-50 has 23,536,718 trainable parameters (≈23.5 million parameters).
  10. What is one limitation of your selected architecture?
    ResNet-50 requires relatively high memory and computation bandwidth (≈4.1 GFLOPs per pass) compared to mobile-optimized architectures, necessitating edge GPU acceleration for ultra-high-speed multi-camera deployments.
  11. How can your model be improved for deployment?
    The model can be converted to ONNX / TensorRT format and quantized using INT8 precision quantization, which reduces memory footprint by 75% and accelerates inference by 3× on embedded edge hardware.
